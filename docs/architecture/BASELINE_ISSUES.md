## Архитектурные риски baseline

- Две реализации `CreateDocumentModal.vue`; фактически layout использует auto-import `ModalCreateDocumentModal`, то есть компонент из `app/components/modal`. Вторую реализацию нельзя удалять до проверки сценария страницы создания документа.
- Store авторизации инициирует загрузку справочников и создаёт междоменную зависимость.
- API, composables, stores и types организованы глобальными техническими слоями.
- Отсутствуют публичные API модулей и автоматические проверки границ.
- `shared/types/index.ts` является широким barrel export и скрывает реальные зависимости.
