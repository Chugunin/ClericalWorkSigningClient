# Правила публичного API модулей

## Единственная точка входа

Внешний код импортирует модуль только так:

```ts
import { DocumentCreateScreen } from '~/modules/document-create'
```

Запрещён обход:

```ts
import DocumentCreateScreen from '~/modules/document-create/components/DocumentCreateScreen.vue'
```

## Что экспортировать

Допустимо:

- экран или компонент, предназначенный для внешнего использования;
- store/composable, если другой слой действительно должен управлять этим контрактом;
- стабильный потребительский тип;
- чистую функцию, если она является частью осознанного доменного API.

Обычно не экспортируются:

- API transport implementation;
- mapper;
- внутренние секции экрана;
- DTO, используемые только внутри модуля;
- lifecycle helpers;
- детали store state.

## Требования к `index.ts`

- явные именованные экспорты предпочтительнее `export *`;
- одинаковые публичные имена запрещены;
- public API должен быть минимальным;
- удаление или переименование публичного экспорта рассматривается как изменение контракта;
- новый экспорт добавляется только при наличии внешнего потребителя.

## Типы

Тип, принадлежащий модулю, экспортируется из его `index.ts`. JSON DTO, используемый client и server, импортируется точным путём из `#shared/contracts/**`.

Не создавать глобальный barrel для всех contracts.

## Проверка

Каждый модуль должен иметь контрактный тест, который фиксирует ожидаемый набор экспортов и запрещает внутренние импорты потребителей.
