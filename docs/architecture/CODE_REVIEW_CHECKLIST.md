# Checklist code review

## Владение и размещение

- [ ] Изменение находится у единственного бизнес-владельца.
- [ ] Новый код не возвращает глобальные roots `app/components`, `app/api`, `app/stores`, `app/types`, `app/utils`.
- [ ] В `shared` нет предметной логики.
- [ ] Пустые каталоги и временные compatibility-файлы не добавлены.

## Зависимости

- [ ] Межмодульные импорты идут только через `~/modules/<name>`.
- [ ] Нет цикла зависимостей.
- [ ] `shared` не импортирует modules.
- [ ] server не импортирует client modules.
- [ ] Новый public export действительно нужен внешнему потребителю.

## UI и маршруты

- [ ] Route-файл остаётся тонким адаптером.
- [ ] Поведение интерфейса не было додумано без подтверждённого сценария.
- [ ] Loading/error/empty states сохранены или явно согласованы.
- [ ] Нет дублирующей реализации компонента или composable.

## Данные и API

- [ ] UI-модель отделена от transport DTO mapper-ом.
- [ ] Shared contract JSON-safe и не содержит framework-типов.
- [ ] Server endpoint тонкий; внешний вызов находится в gateway.
- [ ] Upstream status/error не теряются без причины.
- [ ] Object URL, AbortController и другие ресурсы корректно освобождаются.

## Качество

- [ ] Добавлены unit/contract/regression tests.
- [ ] Архитектурный тест обновлён только из-за осознанного изменения границы.
- [ ] Документация и `MODULE_MAP.md` актуальны.
- [ ] `npm run check` проходит.
