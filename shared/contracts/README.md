# Shared contracts

Этот каталог содержит только сериализуемые DTO, пересекающие границу browser ↔ Nuxt server ↔ external API.

Правила:

- запрещены импорты Vue, Nuxt, Pinia, UI-библиотек и модулей приложения;
- контракты не содержат реактивное или изменяемое UI-состояние;
- UI/domain-модель преобразуется в DTO через mapper на границе;
- импорты выполняются по точному файлу, общий barrel отсутствует;
- имена request/response/contract отражают назначение типа.
